# Start here

This is the Distributed Real-Time Systems and Networks interactive MATLAB track. Run `./bin/learn status`, then
`./bin/learn start`. P01 is the implemented reference, and P02 through P10 are implemented learning
slices; the manifest and `./bin/learn list` are authoritative as later one-to-one Portfolio Control
batches advance. A learner session follows read → visualize → move one lever → visualize the change
→ read/explain, then a broken case, checks, and teach-back.

Use `docs/CURRICULUM_AUDIT.md` for the complete phase and batch map.
