## Governing numerical contract

Node-local clock `i` is

```text
C_i(t) = t + e_i
```

where `e_i` is node-local time minus coordinator true time. A positive offset is ahead. A shared
activation timestamp `A` and node phase `s_i` therefore produce true start

```text
t_i = A + s_i - e_i.
```

Every action occupies the same exclusive, non-preemptive shared communication channel over the
half-open interval `[t_i,t_i+160 us)`. Zero separation means touching without overlap; negative
separation means two nodes request that exclusive channel concurrently. True starts relative to
activation are sorted before adjacent gaps are calculated, and the last-to-first cycle-wrap
transition is included. Relative arithmetic prevents a large common activation epoch from erasing
a representable gap or overlap.

Adjacent negative gaps are sufficient to detect unsafe occupancy and their overlap sum is the
aggregate time by which requests exceed the one-channel capacity. They are not an exhaustive
collision-pair inventory during three-way contention. The model therefore checks all six unordered
node pairs on the cyclic timeline; `collisionCount`, collision endpoints, and pairwise-overlap
totals include every conflicting pair, while transition and resource-overcommit metrics retain the
adjacent-gap meaning used by the plots.

The coherent cycle is `1000 us`; slot spacing is `250 us`; nominal guard is `90 us`. If
`|e_i|<=E`, then `|e_i-e_j|<=2E`, so every adjacent separation in one coherent slot map satisfies

```text
minimum separation >= 90 us - 2E.
```

The deterministic offset fixture is `E*[-1 0.5 1 -0.5]`. Version 1 phases are
`[0 250 750 500] us`; version 2 phases are `[0 250 500 750] us`. Each complete map is
collision-free on the exclusive channel under baseline error; version coherence does not by itself
prove sufficient clock guard. Publication is true time zero. True schedule-ready time is

```text
ready_true_i = distribution_scale * [180 420 760 1120]_i
             + [80 80 120 100]_i us,
ready_local_i = ready_true_i + e_i.
```

A node is ready exactly when `ready_local_i <= A`. Half-open overlap is also classified exactly:
zero separation touches, while every negative computed separation overlaps. No numerical tolerance
widens either semantic boundary. If every node is ready, the policy oracle selects version 2
everywhere. If any node is late and all-or-nothing is enabled, it withholds the new selection and
every node retains version 1. If the policy is disabled, ready nodes select version 2 independently
while late nodes retain version 1. This is a truth-based selection fixture, not an implemented
acknowledgment, transaction, abort, consensus, or rollback protocol.

Baseline `(E, A, distribution scale, all-or-nothing) = (20,1500,1,true)`:

- offsets: `[-20 10 20 -10] us`; pairwise span `40 us`;
- true ready times: `[260 500 880 1220] us`;
- local ready times: `[240 510 900 1210] us`;
- readiness slack: `[1260 990 600 290] us`; all four ready;
- active versions: `[2 2 2 2]`; selected phases `[0 250 500 750] us`;
- true starts: `[1520 1740 1980 2260] us`, or `[20 240 480 760] us` relative to `A`;
- ends relative to `A`: `[180 400 640 920] us`;
- cyclic gaps: `[60 80 120 100] us`; actual minimum `60 us`;
- conservative bound: `90-2(20)=50 us`; no overlap; and
- cycle utilization: `4(160)/1000=0.64`.

Clock-bound sweep at fixed `A=1500 us`:

| `E` (us) | Pairwise offset span (us) | Actual minimum gap (us) | `90-2E` bound (us) | Maximum start displacement (us) |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 0 | 90 | 90 | 0 |
| 20 | 40 | 60 | 50 | 20 |

At `E=45 us`, the general guarantee reaches zero while this exact fixture retains `22.5 us`.
At `E=60 us`, one pair touches with zero gap and no overlap. At `E=61 us`, the coherent fixture
overlaps by `1.5 us`. A representable input just above `60 us` is also required to produce a
strictly negative gap and a collision, independently checking that tolerance cannot hide overlap.

At the accepted maximum `E=250 us`, coherent version 2 starts relative to activation are
`[250 125 250 875] us`. Sorted gaps are `[-35 -160 465 90] us`, so two adjacent transitions are
negative and aggregate channel overcommit is `195 us`. Nodes B/A, A/C, and B/C are nevertheless
three distinct conflicting pairs with overlaps `[35 160 35] us`; exhaustive collision count is
three and total pairwise overlap is `230 us`.

Activation-lead sweep at fixed `E=20 us` and version-coherent policy:

| ---: | ---: | ---: | ---: | ---: |

At `A=1210 us`, Node D is ready exactly at the boundary and all nodes activate version 2. At
the representable value `1210-1e-12 us` and at `A=1209 us`, Node D is late and the coherence
policy retains version 1 everywhere.
With distribution scale zero, validation still costs `[80 80 120 100] us`; local ready times are
`[60 90 140 90] us`, so `A=140 us` is the exact all-ready boundary.

The deliberately broken case uses `A=1000 us` and disables all-or-nothing. Nodes A–C are ready,
Node D is late, and versions become `[2 2 2 1]`. Selected phases `[0 250 500 500] us` produce
relative starts `[20 240 480 510] us` and cyclic gaps `[60 80 -130 350] us`. Node C overlaps
Node D by exactly `130 us`. The coherence policy at the same lead retains version 1 with sorted node
order A, B, D, C and gaps `[60 110 60 130] us`; restoring `A=1500 us` activates version 2 without
collision.

At `A=600 us` with the policy disabled, versions `[2 2 1 1]` are mixed but have no overlap in this
fixture because both changed Node C/D assignments remain old. This branch proves that absence of
one visible collision symptom does not establish version coherence. At `E=100 us`, even coherent
version 2 overlaps because clock error consumes too much guard; all-or-nothing protects version
coherence, not timing safety.

## Model basis and inference boundary

The abstraction is grounded in primary standards material, while every fixture value and the
all-ready policy are local engineering choices:

- IEEE 802.1Qbv specifies scheduled frame transmission based on timing derived from IEEE 802.1AS:
  <https://www.ieee802.org/1/pages/802.1bv.html>.
- IETF RFC 9320 states that scheduled traffic depends on a synchronized network and coordinated
  gate-control configuration: <https://datatracker.ietf.org/doc/rfc9320/>.
- IETF RFC 8655 describes repeating schedules synchronized among DetNet nodes and the tradeoff
  between fine-grained scheduling and resource use: <https://datatracker.ietf.org/doc/rfc8655/>.

Inference: these sources support separating shared time from coordinated schedule configuration.
They do not validate this two-version slot map, delays, staging costs, clock fixture, policy oracle,
MATLAB source, or any network/device behavior. P08 is not an IEEE 1588, IEEE 802.1AS/Qbv, DetNet,
TSN, or TTEthernet conformance implementation.
