## Governing model and exact deterministic reference

One sequential transaction has five declared analytical timing contributions:

`c = [source task response, queue/admission wait, serialize + network, coordination evidence wait, destination task response]`.

For end-to-end deadline `D`, complete contribution `R_e2e`, stage allocations `b_i`, stage margins
`M_i`, end-to-end slack `S_e2e`, and unassigned reserve `R`,

`R_e2e = sum(c_i)`

`S_e2e = D - R_e2e`

`M_i = b_i - c_i`

`R = D - sum(b_i)`.

When every causal stage is owned exactly once, `S_e2e = R + sum(M_i)`. A credible modeled plan
has complete coverage, all stage margins nonnegative, and an allocation sum no larger than `D`.
These are accounting rules over declared synthetic values, not proof that the values are certified
physical upper bounds.

The baseline is `(queue,coordination,D,includeCoordination)=(12 ms,26 ms,90 ms,true)`.

import itertools
import math

queue_values = [0, 12, 16, 24, 1000]
coordination_values = [0, 1, 26, 32, 60, 100, 999, 1000]
deadline_values = [0, 27, 39, 52, 60, 65, 84, 90, 2027, 1_000_000]

case_count = 0

for queue_ms, coordination_ms, deadline_ms, include_coordination in itertools.product(
    queue_values, coordination_values, deadline_values, coverage_values
):
    contributions = [8, queue_ms, 10, coordination_ms, 9]
    budgets = [10, 16, 14, 32, 12]
    owned = [True, True, True, include_coordination, True]
    accounted = [value if is_owned else 0 for value, is_owned in zip(contributions, owned)]
    assigned = [value if is_owned else 0 for value, is_owned in zip(budgets, owned)]
    margins = [
        budget - contribution
        for contribution, budget, is_owned in zip(contributions, budgets, owned)
        if is_owned
    ]
    full_total = sum(contributions)
    accounted_total = sum(accounted)
    assigned_total = sum(assigned)
    unowned_total = full_total - accounted_total
    full_slack = deadline_ms - full_total
    apparent_slack = deadline_ms - accounted_total
    reserve = deadline_ms - assigned_total
    margin_total = sum(margins)
    cumulative_full = list(itertools.accumulate(contributions, initial=0))
    cumulative_accounted = list(itertools.accumulate(accounted, initial=0))
    cumulative_assigned = list(itertools.accumulate(assigned, initial=0))

    assert full_total == 27 + queue_ms + coordination_ms
    assert 27 <= full_total <= 2027
    assert len(contributions) == 5
    assert len(cumulative_full) == len(cumulative_accounted) == len(cumulative_assigned) == 6
    assert cumulative_full[-1] == full_total
    assert cumulative_accounted[-1] == accounted_total
    assert cumulative_assigned[-1] == assigned_total
    assert unowned_total == (0 if include_coordination else coordination_ms)
    assert math.isclose(
        full_slack - (reserve + margin_total), -unowned_total, abs_tol=1e-9
    )
    assert math.isclose(
        apparent_slack - (reserve + margin_total), 0, abs_tol=1e-9
    )
    owned_stages_fit = all(margin >= 0 for margin in margins)
    credible = include_coordination and owned_stages_fit and assigned_total <= deadline_ms
    if credible:
        assert full_total <= deadline_ms
    false_confidence = (
        not include_coordination
        and accounted_total <= deadline_ms
        and full_total > deadline_ms
    )
    if false_confidence:
        assert apparent_slack >= 0 and full_slack < 0 and unowned_total > 0
