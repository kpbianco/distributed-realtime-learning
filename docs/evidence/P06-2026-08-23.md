## Governing numerical contract

Sign convention: `theta = server clock - client clock`. For client send time `T0`, forward delay
`d_f`, reverse delay `d_r`, and server residence `p`:

```text
T1 = T0
T2 = T0 + d_f + theta
T3 = T0 + d_f + p + theta
T4 = T0 + d_f + p + d_r

theta_hat = ((T2-T1) + (T3-T4))/2
          = theta + (d_f-d_r)/2

delta_hat = (T4-T1) - (T3-T2)
          = d_f + d_r
```

Baseline `(T0, theta, d_f, d_r, p) = (100, 7, 4, 4, 2) ms`:

- simulated true event times: `[100 104 106 110] ms`;
- endpoint-local timestamp observations `[T1 T2 T3 T4]`: `[100 111 113 110] ms`;
- signed offset terms `T2-T1` and `T3-T4`: `11 ms` and `3 ms`;
- estimated/true offset: `7/7 ms`;
- client elapsed/server residence: `10/2 ms`;
- estimated/true network round trip: `8/8 ms`;
- inferred symmetric one-way delay: `4 ms`; and
- all offset, round-trip, response, and processing-cancellation identities: zero residual.

The offset sweep `[-8 0 12] ms` produces identical offset estimates, fixed `8 ms` network round
trip, and fixed `10 ms` client elapsed time. The symmetric one-way delay sweep `[1 4 10] ms`
produces fixed `7 ms` offset estimates, network round trips `[2 8 20] ms`, and client elapsed values
`[4 10 22] ms` with the fixed `2 ms` server residence.

The deliberately broken case `(100, 7, 7, 1, 2) ms` and symmetric alias
`(100, 10, 4, 4, 2) ms` both expose `[100 114 116 110] ms`. The broken case estimates `10 ms`
instead of the true `7 ms`; half its signed `6 ms` path asymmetry appears as `+3 ms` offset error.
It infers `4/4 ms` directional delays instead of truth `7/1 ms`, yet retains an `8 ms` network
round trip and zero governing-equation residual. Symmetry status is simulator truth and is not
endpoint-observable.
