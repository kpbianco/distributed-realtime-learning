## Governing deterministic contract

One primary accepts version `1`, value `65%`, at time zero; all replicas initially expose version
`0`, value `40%`. For replica `i`, propagation scale `s`, base propagation delay `d_i`, and apply
cost `c_i`, the exact visibility boundary is

```text
t_apply_i = s*d_i + c_i.
```

The fixed delays are `[0 10 30 70] ms` and costs are `[0 5 5 5] ms`. At baseline scale `1`,
apply times are `[0 15 35 75] ms`. A replica is current at time `t` exactly when it is online and
`t_apply_i <= t`; the exact boundary is included and no numerical tolerance widens it.

For required acknowledgment count `W`, the fixture sets acknowledgment-return delay to zero and
loss to absent, so observed acknowledgment time equals apply time. Response time is the `W`-th
order statistic of those online observations when that finite time is no later than the timeout.
The zero-cost return is an explicit teaching oracle, not a transport model. Otherwise the response
is a timeout classification at the configured deadline. The function performs no wait. An
immediate read always targets Replica D so routing is visible.

At baseline `s=1`, `W=4`, zero post-response read delay, D online, and timeout `160 ms`, the write
responds at `75 ms`; all four replicas expose version `1`; D returns `65%`; and accumulated
version lag is `0+15+35+75=125 replica-ms`.

Propagation-scale sweep `[0.5 1 2]` independently yields:

| Scale | Apply times (ms) | W=4 response / convergence (ms) | Lag exposure (replica-ms) |
| ---: | --- | ---: | ---: |
| 0.5 | `[0 10 20 40]` | 40 | 70 |
| 1 | `[0 15 35 75]` | 75 | 125 |
| 2 | `[0 25 65 145]` | 145 | 235 |

Acknowledgment-count sweep `[1 2 4]` at baseline delay independently yields:

| W | Response (ms) | Current replicas at response | Immediate D version |
| ---: | ---: | ---: | ---: |
| 1 | 0 | 1 | 0 |
| 2 | 15 | 2 | 0 |
| 4 | 75 | 4 | 1 |

The deliberately broken case uses `W=1` and an immediate D read. The primary acknowledges at
`0 ms`, but D applies at `75 ms` and successfully returns stale version `0`/`40%`. The named
violation is treating an acknowledgment threshold as universal visibility. Requiring `W=4` or
waiting until the exact `75 ms` read boundary produces version `1` in this fixture.
