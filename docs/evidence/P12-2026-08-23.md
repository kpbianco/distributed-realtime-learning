## Governing model and exact deterministic reference

One proposer asks five fixed nodes for one vote each on value `65`. Potential vote evidence from
node `i` is observed at

`T_i = s*(d_out_i + d_return_i) + p_i`.

The fixture uses outbound and return delay vectors `[0 6 12 18 30] ms` and processing vector
`[0 2 2 2 2] ms`. This evaluator observes one certificate if the `q`-th distinct online vote is no
later than its timeout or pending cancellation; complete quorum evidence wins an exact tie. A
timeout or cancellation closes only the evaluator's observation window. The later potential
quorum time remains available when the quorum is reachable, but post-resolution protocol progress
is not modeled. If cancellation and timeout tie without certificate evidence, cancellation
classifies the local result. Two threshold-sized sets in fixed membership `N=5` overlap by at least
`max(0,2q-N)` nodes. Blocking conflicting certificates also relies on the named assumption that a
node votes for at most one value in the same term/slot. Node 1 is the fixed online proposer/local
voter; proposer failure and election are not modeled.

The baseline is `(s,q,timeout,node5Online,cancel)=(1,3 votes,100 ms,true,false)`.

| Baseline quantity | Independently recomputed value |
| --- | --- |
| Base round-trip delay | `[0 12 24 36 60] ms` |
| Processing time | `[0 2 2 2 2] ms` |
| Potential vote times | `[0 14 26 38 62] ms` |
| Certificate | evaluator observes nodes `[1 2 3]` and reports value `65` at `26 ms` |
| Retained cumulative evidence | `[1 2 3]` votes at `[0 14 26] ms` |
| Evidence not needed at resolution | two slower online votes |
| Quorum geometry | minimum intersection `1 node`; conflicting certificates blocked only under the one-vote assumption |
| One-round availability | quorum remains reachable with two follower voters unavailable while the fixed proposer remains online; live UI exposes Node 5 availability only |

Two independent sweep contracts passed:

| Sweep | Inputs | Exact retained outputs |
| --- | --- | --- |
| Round-trip delay scale | `[0 0.5 1 2]`, all other baseline inputs fixed | decision latency `[2 14 26 50] ms`; potential vote-time spread `[2 32 62 122] ms`; votes observed at resolution `[5 3 3 3]` |
| Quorum size | `[2 3 4 5] votes`, all other baseline inputs fixed | decision latency `[14 26 38 62] ms`; minimum intersection `[0 1 3 5] nodes`; unavailable-follower tolerance `[3 2 1 0] nodes` with the proposer online; intersecting threshold flags `[false true true true]` |

The deliberately broken threshold uses `q=2`. Certificate X `{1,2}` and certificate Y `{4,5}`
are disjoint, so two conflicting values can each meet the configured threshold without a common
voter. The named violated assumption is “any fast threshold is enough for agreement.” This is a
combinatorial certificate witness, not an executed partition, concurrent-leader run, or protocol.
